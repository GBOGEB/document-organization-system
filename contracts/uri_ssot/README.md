# URI SSOT contract (`gbogeb.uri-ssot/1`)

One resolver for artifact references across the federation, in two languages that are held to the same hand-written vectors:

| File | Role |
|---|---|
| `resolver.py` | Python reference (standard library only) |
| `Resolve-GbogebArtifactUri.ps1` | PowerShell 7.2+ port (`Resolve-GbogebArtifactUri`, `ConvertTo-GbogebRelativeReference`) |
| `vectors.json` | Expected outputs, written from RFC 3986 / RFC 8089, not generated by either implementation |
| `uri-ssot-contract.schema.json` | Draft-07 schema of one contract |
| `../../tests/test_uri_ssot.py`, `../../tests/Resolve-GbogebArtifactUri.Tests.ps1` | Gates; CI runs Python on Ubuntu and Pester on Ubuntu and Windows (`.github/workflows/uri-ssot-contract.yml`) |

## Rules

- **DOV-1** — `null`, empty or whitespace-only input resolves to `null`.
- **DOV-2** — `file:///C:/x` has an *empty* authority (`""`, `has_authority: true`); `urn:a:b` has *no* authority (`null`, `has_authority: false`).
- **DOV-3** — `foo:bar/baz` is an **absolute URI with scheme `foo`** (RFC 3986 §3.1) and is never demoted. The `./` prefix applies when *writing* a relative reference whose first segment contains a colon (§4.2): `to_relative_reference("foo:bar/baz") == "./foo:bar/baz"`.
- Windows drive paths (`C:\x`, `C:/x`) and UNC paths (`\\host\share`) are file-system paths and become `file:` URIs (RFC 8089 appendix E); `kind` records the origin.
- `javascript:`, `vbscript:` and `data:` are parsed as written and flagged `executable_scheme: true`, so consumers can refuse them.
- Normalization follows RFC 3986 §6.2.2: lower-case scheme and host, upper-case percent-encoding hex, remove dot segments in hierarchical paths. `canonical` is idempotent.
- `#oid:<dotted>` fragments yield `fragment_oid`. No OID is defaulted or invented. (`1.3.6.1.4.1.99999` appears in a vector only as sample input; it is not a registered GBOGEB enterprise number.)

## Use

```bash
python contracts/uri_ssot/resolver.py "C:\\gg_MATH\\manifest.json"
```

```powershell
. ./contracts/uri_ssot/Resolve-GbogebArtifactUri.ps1
Resolve-GbogebArtifactUri 'file:///C:/gg_MATH/manifest.json'
```

Origin: the Gemini "gg_MATH v3" handover of 2026-11-15 proposed this resolver with DOV-3 as "demote `foo:` to a relative path" and a fixed default OID. Both were changed to the RFC behaviour above; see the PR that introduced this folder.
