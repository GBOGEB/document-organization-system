# Next victory condition — v1.2 Federated Mission Dispatch + Responder Runtime

The v1.1 loop can create a cause-bound route, emit a governed handshake, discover a return artifact, verify exact-SHA execution evidence, close only the originating external assignment, federate closure state, and trigger local requalification.

The remaining discontinuity is **outbound actuation**.

## First-red

`Gloob external handshake exists, but no governed mechanism has yet caused the addressed target repository to start the assigned work.`

Do not attack PCA residuals, PC2/PC3/PC4 variance, generic workers, or broader federation while this boundary remains red.

## v1.2 victory

A real, bounded dispatch must prove the complete loop:

1. Gloob emits one deterministic route and handshake for an actually changed/failed causal epoch.
2. A dispatch envelope is delivered to exactly one authorized target repository.
3. The target repo accepts the envelope idempotently and rejects replay/stale assignment identity.
4. A repo-local responder selects or validates an eligible crew/capability surface.
5. A real workflow executes more than zero steps on an exact SHA.
6. The target publishes `gloob-causal-return` with the same `route_id` and `assignment_digest`.
7. Gloob federates the return without manual JSON copying.
8. v1.1 verification accepts or rejects it deterministically.
9. A valid `RESOLVED` return closes only the external route and starts local causal requalification.
10. CONTROL is restored only after Gloob's local qualification rules pass; the external return itself earns no CONTROL credit.

## Minimum v1.2 outputs

- dispatch-envelope.json
- dispatch-ledger.json
- delivery-acknowledgement.json
- responder-capability decision/receipt
- target-repo exact-SHA execution receipt
- gloob-causal-return artifact
- round-trip closure/requalification proof

## STOP condition

When one real end-to-end route round trip is exact-SHA proved on both Gloob and the target repository, stop and reassess before scaling fan-out, retries, crew optimization or mission orchestration.
